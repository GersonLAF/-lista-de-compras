# Lista de Compras
Prova

A aplicação permite que usuários criem e gerenciem uma lista de compras pessoal, utilizando autenticação com Clerk e armazenamento dos dados em PostgreSQL através do Prisma ORM.

## Funcionalidades

* Login de usuários com Clerk
* Cadastro de itens
* Edição de itens
* Exclusão de itens
* Marcar item como comprado
* Definição de prioridade (Alta, Média e Baixa)
* Regra de negócio para limitar até 5 itens de prioridade alta pendentes
* Dashboard com informações da lista

## Tecnologias Utilizadas

* Next.js 16
* TypeScript
* Clerk
* Prisma ORM
* PostgreSQL
* Tailwind CSS
* shadcn/ui
